2026-10-12 本次修改：
- 应用显示名称、服务通知名称改为“游标”。
- 使用新生成的定位点与方向箭头图标，提供 Android 自适应图标和单色通知/主题图标。
- 使用用户独有的 RSA 4096 位签名密钥；不再使用上游公开私钥签名。
- 签名配置从独立 signing.properties 加载，避免地图密钥插件把签名密码写进 BuildConfig。
- 缺少签名配置时构建直接失败，不会回退到上游公开签名。

保留此前个人版修复：
- 拒绝失败定位回调中的无效坐标，用户选点后迟到的首次定位不再覆盖所选位置。
- 尚未获得有效定位时给出提示并保留选点。
- local.properties 配置个人百度 Android AK 与签名安全码。
- 修复随附 SDK 的 SetIgnoreCacheException 方法名编译问题。
- compileSdk 36，targetSdk 32，最低 Android 8.1，ARM64。
- 声明 Android 16 页大小兼容模式。
- 首次进入仅请求必要定位权限，搜索防抖、取消过时请求、无城市时搜索支持。
- 修正手输 WGS84 经纬度顺序，释放悬浮窗搜索/计时器，处理服务空启动 Intent。
- 关闭上游在线自动更新，避免个人版本被原版覆盖。

用户已在百度控制台更新签名，SDK 在线鉴权已实际返回 success。
签名私钥与密码单独保存在个人签名备份中，不进入源码包。
公开证书可用于核对指纹；私钥与密码不要随 APK 或源码分享。

构建：
1. 准备 JDK 17、Android SDK Platform 36、Build Tools 36.0.0、Gradle 8.13。
2. 复制 local.properties.example 为 local.properties，填写 SDK 路径、百度 AK 与证书安全码。
3. 复制 signing.properties.example 为 signing.properties，填写私钥路径、别名、密码。
   签名密码不要写入 local.properties，以免被地图密钥插件打进 BuildConfig。
4. ./gradlew :app:assembleRelease
5. 输出 app/build/outputs/apk/release/Youbiao_1.12.3-youbiao.1_arm64-v8a_release.apk。
