# Youbiao

A personal Android mock-location build based on [ZCShou/GoGoGo](https://github.com/ZCShou/GoGoGo), with a new app name and icon, independent signing configuration, configurable Baidu credentials, and fixes for search and Android compatibility.

Version: `1.12.3-youbiao.1`. ARM64, Android 8.1 or newer.

See the [Chinese README](README.md) for build instructions, changes, installation steps and validation scope. Supply your own `local.properties` and `signing.properties`; private credentials and pre-signed APKs are excluded from this repository.
